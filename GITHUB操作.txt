前置作業(設定git環境、連接遠端repository等等)參考Line群組記事本連結(GITHUB教學)。

每次作業前，先在VSCode的Source Control將repository同步(可能是extension “github history”內的功能)。

之後修改完程式碼後，
Git add .
Git commit -m “message”
git pull origin branch1
git push origin branch1


以下列出可能會用到的指令：
git checkout main
Git remote add origin https://github.com/RoryH093/NCUE_test2.git
Git branch -M branch1

我的想法是：
我們github的branch有main, branchP, branchJ, branchR。
每個人寫完的放到自己的branch後，再自己發pull request去merge到main。
這樣我們每次自己在寫的時候，都可以先跟main的同步。
